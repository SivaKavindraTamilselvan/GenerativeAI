# Reimbursement Policy

To file a reimbursement:
1. Log in to the Finance Portal (finance.company.com).
2. Go to "Expenses" > "New Reimbursement Request".
3. Attach itemized receipts (required for expenses over $25).
4. Select the correct cost center / project code.
5. Submit for manager approval.

Reimbursements are processed within 5-7 business days after approval.
